Switch is an iOS-style on/off toggle for settings such as notifications.

- 44 × 26 with a white 20px knob. Off is `#d9d9d9` and on is `accent`.
- It is a native `<input type="checkbox">`, so the consumer provides a visible label next to it.
- The off track is only 1.4:1 against white, which is below the 3:1 floor. The source keeps this value. Pair the switch with its label and on/off state.
