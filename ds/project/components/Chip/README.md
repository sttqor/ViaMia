Chip is a pill filter for categories («Все», «Практики», «Еда»): 36px tall (`h-chip`) with `radius-chip` corners.

- Unselected: `card` fill, 1.5px `line` border, `ink` label.
- Selected (`aria-pressed="true"`): `ink` fill and border, white label.
- Chips sit in a horizontal scroll row, `space-8` apart, with a `space-16` gutter.
- The consumer provides the label and the pressed state. Only one chip in a row is selected.
