IconButton is a round, white, 44px button (`size-icon-btn`) for back, save and search.

- `card` fill, a 1px `line` border and an `ink` icon at 20px. It is solid white, never glass.
- `og-icon-btn--photo`: 38px, used for the save heart over a card photo, top-right with an 8px inset.
- The save heart is stroked in `accent`.
- The consumer must give it an `aria-label` from `t()` («Назад», «Сохранить»).
