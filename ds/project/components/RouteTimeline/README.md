RouteTimeline is the day plan on the Route tab: time, stop and travel time.

- A 46px rail shows the time in 11px/800 `ink-soft`, a 10px `accent` dot with a white ring, and a dashed 2px line.
- Each stop is a card with 12px padding: a 56px thumbnail (`radius-thumb`), its title and meta, and a text link in `accent-hover`.
- The consumer provides an ordered list of stops with start times.
- In code the line still uses an older blue (`#b9c6d8`). Here it uses `line`.
