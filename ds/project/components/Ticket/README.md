Ticket is the booking confirmation shown after a booking request and in Profile.

- A `card` ticket with `radius-card` corners and `shadow-float`. The body has 16px padding, then a dashed tear line with two `bg` notches.
- Below it, the booking code sits in an `ink-deep` block with white 18px/800 text and 3px tracking.
- The consumer provides the tour copy, date, guests and the code from `makeCode()`.
