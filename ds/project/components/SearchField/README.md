SearchField is a 48px search input on screen headers and the map.

- `bg` fill, a 1.5px `line` border and `radius-btn` corners, with an 18px `muted` search icon and 14px `ink` text.
- Over the map, add a float shadow so it stands off the tiles.
- The consumer provides the placeholder from `t()` («Поиск…», «Найти место на карте…») and handles the input.
