Badge is a small label on photos, in detail rows and on tags.

- **On photo** (default): a white pill with 11px/800 `ink` text, 10px from the photo's top-left corner.
- **Gold** (`--gold`): a `gold` pill with `ink-deep` text and 0.04em tracking. Use it only for tags and overlines.
- **Soft** (`--soft`): `bg-2` with `ink-soft` text, for facts like duration and place.
- **Success** (`--success`): `success` text on `success-bg`, always with a check icon.
