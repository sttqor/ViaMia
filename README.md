# ViaMia — гид по Ошу

Туристы смотрят места на карте, собирают маршрут на день и бронируют туры у проверенных агентств; агентства ведут туры и заявки в кабинете.

- Сайт (Vite + React): `npm install && npm run dev`, сборка — `npm run build`. Выкладывается Vercel из ветки `main`.
- Приложение (Expo / React Native): папка `mobile/`, см. раздел «Мобильная версия на Expo» в `CLAUDE.md`.
- Всё о проекте — `CLAUDE.md`; сводка для нового чата — `playbooks/HANDOFF.md`; база и вход — `supabase/`.
