# плейбук: выпуск ViaMia в app store и google play

## цель
то же приложение (vite + react) выходит в app store и google play как настоящее приложение
через capacitor: иконка ViaMia, заставка, работа без интернета, карта «как 2гис»,
понятные экраны загрузки и ошибок, политика конфиденциальности и удаление аккаунта —
всё, без чего магазины не пропустят.

## что решил пользователь (20.11.2026)
1. обёртка — **capacitor** (минусы объяснены, согласен). react native — потом, только если упрёмся.
2. mac нет → ios собираем в облаке (**codemagic**), android — на windows.
3. юрлица нет → аккаунты разработчика **лично** (apple 99 $/год, google 25 $). регистрирует сам пользователь.
   google для нового личного аккаунта требует закрытый тест: **12 тестеров × 14 дней** — пользователь соберёт.
4. название **ViaMia**, логотип — квадрат в конце заставки (`src/splash.mp4`).
5. push-уведомления — потом.
6. тест — на своих iphone и android.
7. к запуску 1–2 реальных агентства.
8. почта поддержки — viamiasupp@gmail.com. домен viamia.com занят; свободны viamiaapp.com (~12 $/год) и viamia.guide (11 $, продление 35 $). пока — без домена, политика на vercel.
9. языки — потом (ru/en на старте).
10. дизайн — не новый стиль, а доработка: загрузка, ошибки, недочёты + чуть-чуть кыргызской символики (түндүк, узор).
11. офлайн — нужен.
12. карта — наша, но работать должна «как 2гис»; везде кнопки «открыть в 2гис» / «маршрут в 2гис».

## правила
- перед правками `npm run lint`, после — `npm run build`; строки только через `t()`, ключи в ru и en.
- цвета только токенами; символика — тонко, в терракоте/золоте, не флаг на весь экран.
- навигация — свой навигатор (`src/Navigator.jsx`, маршруты OSRM); 2гис — только кнопка «Открыть в 2ГИС». карта — openfreemap + maplibre.
- ничего не регистрировать и не оплачивать за пользователя: аккаунты, домен, ключи — делает он.
- новый файл/шаблон для выпуска — в `toolbox/` и строкой в таблицу ниже.
- **id приложения `kg.viamia.app`** — после первой загрузки в магазин не меняется.
- после правок кода: `npm run build && npx cap sync` — иначе в android/ios останется старая версия.
- иконки/заставка: правим `resources/*.png`, потом `npx capacitor-assets generate --iconBackgroundColor "#D4532B" --splashBackgroundColor "#D4532B"` (созданные ею `icons/` и правку `public/manifest.webmanifest` откатить).
- карта ходит через протокол `osh://` (`src/offlineMap.js`): новые адреса карты — только через `toOsh()`, иначе не будет офлайна.
- поменяли, что собираем (push, аналитика, новый сервис) — обновить `src/privacy-text.js`, дату и анкеты в `toolbox/store-listing.md`.
- удаление аккаунта — только через `delete_my_account()`; владельца агентства и админа она не удаляет специально.
- пакеты ставим точной версией, вышедшей не меньше 2 недель назад (`npm i -E`).

## готово, когда
- приложение ставится на iphone и android из testflight / закрытого теста google.
- открывается без интернета: туры, билеты, избранное, карта оша.
- в профиле есть политика и «удалить аккаунт», ссылка на политику открывается.
- любая ошибка сети показывает понятный экран с «повторить», а не пустоту.
- из места и тура можно построить маршрут во встроенном навигаторе и открыть место в 2гис.
- lint и build без ошибок.
