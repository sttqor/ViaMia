# плейбук: бронь, «поездка», чат и уведомления

## цель
после заявки турист понимает, что происходит: агентство подтверждает → в билете «поездка»
(время встречи, гид с фото, программа, связь, чат), все изменения приходят сразу.
агентство в кабинете ведёт гидов, программу тура, отвечает на заявки и пишет туристу.

## что решил пользователь (21.11.2026)
- чат по брони нужен — **внутри «поездки»/заявки, не отдельной вкладкой**.
- остальное — по моим советам из `PROPOSAL.md`: по одному туру без корзины, бронь только после входа
  по почте, экран «поездка» в билете, гиды списком в кабинете, сгорание через 24 ч,
  телефон гида — только если агентство разрешило, в приложении + письма к 15.12, push — после.
- кабинет агентства сделать «нормальным, с функционалом».
- координироваться с Claude в VS Code напрямую, пользователя не спрашивать.

## правила
- права — только в базе (`toolbox/01-booking.sql`): кто что меняет решают rls, `booking_guard`, `message_fill`. экран только показывает.
- после правки sql — `toolbox/02-test-booking.sql` (откатывается сам, итоги в шапке файла).
- гид и контакты туристу — только через `my_trip()`; напрямую таблицу `guides` турист не читает.
- время встречи — `meet_at` (timestamptz), вводится и показывается по Ошу (Asia/Bishkek).
- строки кабинета и чата — `src/locales/agency.js` (`ag.*`, `chat.*`); туриста — `src/i18n.js` (`trip.*`, `bell.*`).
- файлы туриста (`src/views/*`, `src/App.jsx`), `src/agency/*`, `src/api.js`, supabase — правлю я; Claude в VS Code их не трогает (договорились 21.11).
- проверка в браузере: временное агентство на тестовом номере +996 555 000 002, турист +996 700 000 001 (код 123456), после проверки всё удалить.

## готово, когда
- агентство подтверждает заявку с гидом и временем → у туриста сразу колокольчик и «поездка» с гидом, программой, кнопками связи.
- турист и агентство переписываются в чате брони, сообщения приходят без перезагрузки.
- заявка без ответа 24 ч сгорает, турист видит это.
- чужие заявки, чаты и гиды недоступны (тест `02`).
- `npm run lint` и `npm run build` без ошибок, проверено в браузере.
