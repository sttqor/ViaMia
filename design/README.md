# дизайн osh guide

точная копия утверждённого макета (https://claude.ai/artifact/7zUSk4KrLpTE7MsphuV2tK).

- `tokens.css` — цвета, радиусы, размеры, шрифты. перенести в `src/index.css` как `:root`.
- `00-style.html` — палитра, кнопки, фильтры, иконки-кнопки, навигация.
- `01-home.html`, `02-tours.html`, `03-route.html`, `04-detail.html` — экраны.

открыть любой `.html` в браузере, чтобы посмотреть. все стили инлайн — значения брать оттуда точно.
серые блоки с горой — места для фото, в приложении остаются настоящие фото.
